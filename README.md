# PowerSystem

> 电力系统理论学习 · 费曼检验 · 代码落地

从一个 FTU / 嵌入式工程师的视角，系统学习电力系统理论。目标不是"看懂教材"，而是把原理讲清楚、写出能跑的代码。

---

学习体系分为八层，逐层递进：

| # | 层 | 状态 |
|---|-----|------|
| 0 | **数学工具** — 相量 / 对称分量法 / 标幺制 | ✅ 已完成 |

## 当前进度：第 0 层

[第0层-数学工具.md](第0层-数学工具.md) 已完成，包含三个核心模块：

### 0.1 相量与复数

从发电机物理原理出发，完整推导：

- 为什么发电机天然产生正弦波（洛伦兹力 → e = BLv·sin(ωt)）
- n = 60f/p 的来源（磁极对数、单位换算）
- 滑环 + 碳刷的旋转供电原理
- 相量如何把微分方程变成代数方程（RLC 电路推导）
- 旋转因子 a = e^(j120°) 及其性质

### 0.2 对称分量法

- 正序 / 负序 / 零序的数学定义
- 零序出现 = 接地故障的数学根源
- 变换矩阵与逆变换

### 0.3 标幺制

- 基准值选择（S_base = 100MVA）
- 跨电压等级直接运算
- 典型计算示例

## 学习方法

```
  理论 ←──→ 工程 ←──→ 代码
```

每个知识点从三个维度展开：

| 维度 | 说明 |
|------|------|
| **理论** | 物理原理和数学推导，讲清楚"为什么" |
| **工程** | 对应什么现场现象、FTU 的什么功能 |
| **代码** | 如何用代码表达这个原理 |

每层末尾有 **费曼检验** — 用自己的话讲清楚核心概念，才算过关。
